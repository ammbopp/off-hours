# ฟังก์ชันฝั่งเซิร์ฟเวอร์ (โครงไว้ก่อน)

หน้าที่: ถือคีย์ API ของผู้ให้บริการ AI/เสียง และเป็นจุดเดียวที่หน้าเว็บเรียกเข้ามา — คีย์ API ต้องไม่อยู่ในโค้ดฝั่งหน้าเว็บเด็ดขาด เพราะอ่านได้จากเบราว์เซอร์

ไฟล์ในนี้เป็น "โครง" (handler ที่รับ `Request` คืน `Response` แบบมาตรฐานเว็บ) ยังไม่ผูกกับผู้ให้บริการโฮสติ้งเจ้าใด เพราะยังไม่ตัดสินใจ (ดูหัวข้อ "เรื่องที่ต้องตัดสินใจก่อนเริ่ม" ใน README หลัก) เมื่อเลือกแล้วให้ย้าย/ปรับไฟล์ตามนี้:

| โฮสติ้ง | ย้ายไปที่ |
| --- | --- |
| Vercel | `api/` (ชื่อไฟล์ตรงกับ path, export เป็น Edge Function) |
| Netlify | `netlify/functions/` |
| Cloudflare Pages | `functions/` |

## รายการฟังก์ชัน

| ไฟล์ | ใช้ทำอะไร | เรียกจาก |
| --- | --- | --- |
| `llm/generate-episode.ts` | สร้างตอนใหม่จากคัมภีร์เรื่อง + สรุปตอนก่อน + คำเป้าหมาย | `src/features/story/generateEpisode.ts` |
| `llm/chat-reply.ts` | ให้ตัวละครตอบแชท พร้อมคำแนะนำภาษา (languageTips) | `src/pages/ChatPage.tsx` (ยังไม่ต่อ) |
| `tts.ts` | แปลงข้อความเป็นเสียง เก็บไฟล์ไว้เล่นซ้ำ | หน้าอ่าน/แชทตอนฟังเสียง |
| `stt.ts` | ถอดเสียงพูดของผู้ใช้ (ไมโครโฟน) | ฟีเจอร์พูดตามตัวละคร |
| `realtime-token.ts` | ออกโทเคนชั่วคราวสำหรับต่อ speech-to-speech API ตรงจากเบราว์เซอร์ | หน้าโทรสด |
| `sync.ts` | ซิงก์ข้อมูลในเครื่อง (IndexedDB) กับฐานข้อมูลบนคลาวด์ | ทุกหน้าที่เขียนข้อมูล |

ทุกไฟล์ throw/คืน 501 ไว้ก่อนจนกว่าจะต่อผู้ให้บริการจริง และต้องอ่านคีย์จาก environment variable เท่านั้น (เช่น `process.env.AI_API_KEY`) ห้าม hardcode
