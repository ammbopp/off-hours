# Off Hours

เว็บแอปฝึกภาษาอังกฤษผ่านนิยายและแชท ออกแบบให้เปิดใน Safari แล้ว Add to Home Screen บน iPhone/iPad ใช้งานคนเดียว ไม่มี App Store

รายละเอียดแนวคิด โรดแมป และเหตุผลของการออกแบบทั้งหมดอยู่ที่แผนงานต้นฉบับ:
`แผนพัฒนาแอปฝึกภาษาอังกฤษผ่านนิยายและแชท (iPhone iPad).md` (บนเดสก์ท็อป) — ไฟล์นี้เป็นสรุปโครงสร้างโค้ดที่สร้างไว้แล้วเท่านั้น

## สถานะ

นี่คือ **โครงคร่าวๆ** ไม่ใช่ของจริง: มีหน้าตาและโครงสร้างข้อมูลครบตามแผน แต่ยังไม่ได้ต่อผู้ให้บริการ AI/เสียงใดๆ ทุกจุดที่ต้องต่อจริงมีคอมเมนต์ `TODO` กำกับไว้ ตอนนี้แอปใช้ **ข้อมูลตัวอย่าง** (ตอนที่ 1 สั้นๆ, ตัวละคร 3 คน, แชทตัวอย่าง) เพื่อให้คลิกดูวงจรการใช้งานได้ครบทุกหน้าโดยไม่ต้องมีคีย์ API

## เริ่มรันโปรเจกต์

```bash
npm install
npm run dev
```

เปิดที่อยู่ที่ขึ้นในเทอร์มินัล (ปกติ `http://localhost:5173`) ด้วย Safari บน iPhone/iPad ในเครือข่ายเดียวกัน เพื่อทดสอบ Add to Home Screen และฟีเจอร์เสียง (ดูหัวข้อความเสี่ยงท้ายไฟล์นี้)

## สิ่งที่ยังไม่ทำ (ตามแผน)

- **ต่อผู้ให้บริการ AI จริง**: `src/features/story/generateEpisode.ts` และ `server/llm/*` ยังเป็นโครงเปล่า เลือกผู้ให้บริการ + โฮสติ้งก่อน (ดูหัวข้อ "เรื่องที่ต้องตัดสินใจก่อนเริ่ม" ในแผนต้นฉบับ)
- **นำเข้าคลังคำจริง**: ดาวน์โหลด NGSL/TSL/BSL ตาม `data/wordlists/README.md` แล้วปรับ `src/lib/wordlists/import.ts` ให้ตรงคอลัมน์จริง
- **รอบทวนแบบ FSRS จริง**: `src/lib/srs/index.ts` เป็น fixed-interval ไว้ก่อน
- **เสียง**: ยังไม่มีปุ่มฟังเสียงแบบไฟล์เสียงสังเคราะห์ (ใช้ `speechSynthesis` ของเบราว์เซอร์ชั่วคราวใน `WordCard.tsx`), ยังไม่มีข้อความเสียงในแชท, ยังไม่มีภารกิจฟัง, ยังไม่มีการโทรสด
- **ไอคอนจริง**: `public/icon.svg` เป็นไอคอนตัวแทน ต้องทำ PNG จริงก่อนใช้งานบนเครื่อง (ดู `public/icons/README.md`)
- **ล็อกแอปด้วยรหัสผ่าน**: ยังไม่ทำ ต้องทำก่อนเผยแพร่ URL จริง เพราะใครเปิดลิงก์ก็ใช้เครดิต API ได้
- **ซิงก์กับคลาวด์**: `server/sync.ts` เป็นโครงเปล่า ตอนนี้ข้อมูลอยู่ใน IndexedDB ของเครื่องเดียวเท่านั้น

ลำดับการทำต่อ แนะนำให้ตามสัปดาห์ที่ 1–3 ของขั้นที่ 1 ในแผนต้นฉบับ (นำเข้าคลังคำ → คัมภีร์เรื่อง + สคริปต์สร้างตอน → หน้าอ่านจริง → สมุดคำศัพท์/ตั้งค่า)

## ความเสี่ยงด้านเทคนิคที่ต้องทดสอบก่อน

ทดสอบบน iPhone/iPad จริงตั้งแต่ตอนนี้ (ไม่ใช่แค่ในเบราว์เซอร์คอมพิวเตอร์):

1. เสียงอ่านของเบราว์เซอร์ (`speechSynthesis`) เล่นได้ปกติในโหมด Add to Home Screen หรือไม่
2. การขอใช้ไมโครโฟนทำงานหรือไม่ (ตัวรู้จำเสียงของ Safari ใช้ไม่ได้ในเว็บแอปบนหน้าจอโฮม — ต้องอัดเสียงแล้วส่งถอดเสียงบนคลาวด์เท่านั้น)
3. ข้อมูลใน IndexedDB ยังอยู่หลังไม่เปิดแอปหลายวัน (Safari อาจล้างข้อมูลถ้าพื้นที่เต็มหรือไม่ได้ใช้นาน — ได้ขอ `navigator.storage.persist()` ไว้แล้วใน `src/lib/db/index.ts` แต่ยังต้องทดสอบจริง)
